## Какой идентификатор выбрать

- `@username` — ник после символа `@`;
- ссылка вида `tiktok.com/@username`;
- ID аккаунта, если он известен;
- несколько дополнительных признаков для проверки результата.

Отображаемое имя не является надёжным уникальным идентификатором: одинаковое имя могут использовать разные люди. Username также может измениться.

4. Проверьте стоимость и пополните баланс.
